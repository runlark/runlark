# Self-hosted open source first

Runlark is Apache-2.0 open source, built first for its authors' own team and projects on their own
hardware and subscriptions. A hosted SaaS remains a hypothesis. No SaaS-specific work (billing,
multi-tenant operations, an open/closed split) happens until external teams ask for it. The collaboration
server therefore targets self-hosting; nothing in it may depend on a hosted control plane.
