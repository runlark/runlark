# Changelog

## Unreleased

- Обновлён `url` до `2.5.9` (вместе с требуемым им `form_urlencoded` `1.2.3`) в `Cargo.lock` для закрытия advisory `RUSTSEC-2026-0592`.
- Обновлены все зависимости и Rust crates закреплены точными версиями `=x.y.z`:
  - Rust: `reqwest` `0.13` (явно `native-tls` вместо нового default rustls/aws-lc-rs, плюс feature `query`), `tokio-tungstenite` `0.30`, `tower-http` `0.7`, `sha2` `0.11`, `wit-parser`/`wit-component` `0.263`, `wat` `1.263`, `wasmtime` LTS `48.0.10`, остальные crates до последних patch/minor; удалены неиспользуемые workspace-зависимости `chrono` и `tower`.
  - `runlark-wasm` адаптирован к API `wit-parser`/`wit-component` `0.263` (сохраняется рендер ошибок WIT с позицией в исходнике); `workflows/solo-default/validator.wasm` пересобран из `validator.wat` новым encoder и digest в `manifest.json` обновлён.
  - npm devDependencies обновлены в пределах текущих major (`oxfmt` `0.80.0`, `oxlint` `1.95.0`, `markdownlint-cli2` `0.24.2`, `@types/react` `18.3.31`) и транзитивные пакеты в `package-lock.json`; `@deepseek-ai/*` остаются `0.2.2-rc.3` из-за патча контроллера в `packages/dsh-plugin/patches`.
  - GitHub Actions: `jdx/mise-action` `v5.3.0` (SHA pin; версия mise и её sha256 без изменений); `actions/checkout` `v7.0.1` и `actions/upload-artifact` `v7.0.2` уже последние.

- Завершён этап A2 (командная работа 2–4 человек — PR 3: Team UI, verified CAS, mobile acceptance и сквозной E2E smoke):
  - В `web/src` добавлен FEOD-модуль `modules/team-collab` (Reatom v1001 `withAsyncData`/`withAsync`), контракты/клиент/RU+EN локализация (`common/team-{types,http,i18n,i18n-ru}.ts`, `common/team.css`) и чистые presentational-адаптеры `common/ui/{TeamSyncStatusBar,TeamConnectionCard,TeamMembersInvitesPanel,TeamRunnersDraftsPanel,PromoteTeamDialog,RunnerOwnershipPanel,TaskCommentsPanel,CasArtifactEvidencePanel,MobileAcceptanceBar}.tsx` по контракту `web/DESIGN.md`:
    - управление подключениями к командному серверу, workspace, ролями участников (`owner`/`maintainer`/`member`/`viewer`), списком и отзывом приглашений, принятием приглашений и `solo -> team` promotion с явной блокировкой при наличии активных/незавершённых runs;
    - отображение владельца активного run (`runner_id`, `lease_epoch`), назначение только `online`-раннеров без автоматического takeover и подтверждаемый диалог `cancel-unreachable` (фокус по умолчанию на Cancel);
    - append-only комментарии задачи, offline-черновики (`task_create`, `task_comment`, `plan_edit`), верхняя полоса синхронизации с явной индикацией offline / конфликтов `409` / reconnect и rebase-повтором конфликтных черновиков;
    - интерактивная проверка SHA-256 и предпросмотр CAS-артефактов (включая состояния `verified`, `not synced`, `corrupted`) и mobile acceptance (`< 48em`) с липкой панелью привязанной приёмки и keyboard accessibility.
  - В `runlark-server`, `runlark-cli` и `packages/dsh-plugin` закрыты точечные пробелы для UI и remote acceptance: добавлен `GET /api/v1/workspaces/{wid}/invitations` (без `token_hash`), прокси `GET /api/runlark/artifacts/:digest` с заголовком `X-Runlark-Sha256-Verified`, fallback `GET /api/v1/runs/{id}/diff` на SHA-256-проверенный CAS-дифф при пустом локальном `worktree_path`, привязка `diff`-артефакта в `team_report` и сохранение `server_code` при `409 team_conflict`.
  - Добавлены поведенческие UI-тесты (`scripts/ui-team.test.mjs`) и сквозной многопроцессный A2 E2E smoke (`scripts/smoke-a2.mjs`, подключённый в `scripts/smoke.mjs` и `just smoke` через `scripts/with-test-postgres.mjs`): реальный `runlark-server` с PostgreSQL + 2 локальных демона/раннера + DSH-прокси + смонтированный UI.
  - Обновлены `wasmtime` до LTS `48.0.9` и pinned Rust toolchain до `1.95.0` (`Cargo.toml`, `Cargo.lock`, `rust-toolchain.toml`, `mise.toml`) для закрытия advisories `RUSTSEC-2026-0567` и `RUSTSEC-2026-0573`.
  - Отмечены выполненные пункты A2 в `ROADMAP.md`.

- Реализована клиентская синхронизация, offline gate, runner-агент и CLI/DSH-прокси A2 (PR 2):
  - В `crates/runlark-local` добавлена миграция `0005_a2_collaboration_sync.sql` (`project_sync_bindings`, `task_comments`, `offline_drafts`, `sync_outbox`, `run_ownership`, `team_workspaces`, `team_members`, `team_runners`, `team_auth_sessions`, `runner_buffered_events`, `synced_cas_blobs`), модули `sync_store`, `comment_store`, `draft_store`, `sync_outbox`, `team_auth_store`, а также атомарные `apply_snapshot_atomic`, `apply_events_batch_atomic` (с проверкой непрерывности `cursor_seq`) и `promote_project_to_team_atomic` (с блокировкой при наличии активных runs) внутри `with_immediate_tx`.
  - В `crates/runlark-cli` добавлены фоновые/ручные воркеры `TeamSyncWorker` (snapshot при подключении и при gap, tail `/sync/events`, flush `sync_outbox`, явная фиксация конфликтов `409` на `offline_drafts`/`sync_outbox`, двусторонняя синхронизация CAS с SHA-256 проверкой) и `RunnerAgentWorker` (регистрация runner, heartbeat, строгое выполнение только runs с совпадающим `(runner_id, lease_epoch)`, локальная буферизация событий при обрыве связи и упорядоченный replay после переподключения).
  - Для проектов в режиме `TeamManaged` включён offline gate: `clarify`, `plan`, `start`, `stop`, `resume`, `answer`, plain-text `SendPrompt`, `move`, `accept`, `reject` и `pr` ожидают подтверждения `runlark-server` и никогда не фиксируют авторитетные командные переходы локально в офлайне (`503 team_server_offline`); комментарии, новые задачи и правки планов могут явно сохраняться как `OfflineDraft`.
  - Добавлены маршруты daemon `/api/v1/team/*` и `/api/v1/tasks/{id}/comments`, подкоманды CLI (`project promote-team`, `team {login,members,invite,accept-invite,sync,drafts}`, `runner {register,status,assign,cancel-unreachable}`, `task comment`) и соответствующие прокси-маршруты в `packages/dsh-plugin`.
