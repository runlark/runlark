# Runlark: продукт

Runlark — рабочая доска для разработки с агентами для solo-разработчика и команды из 2–4 человек.
Основная единица — задача с принимаемым результатом; агенты, сессии и попытки могут меняться,
задача и история решений сохраняются. Управление из чата, кнопок и CLI использует одни команды.

## Первый полезный сценарий

Открыть репозиторий, поставить задачи через чат, запустить две независимые задачи, увидеть
прогресс, ответить на вопрос, проверить diff и получить принятое локальное изменение или PR.

Колонки: Входящие → Готово к работе → В работе → Приёмка → Завершено.
Стадия, состояние выполнения и ожидание человека показываются отдельно от колонки.
Перетаскивание проходит доменную проверку; слова агента не принимают результат за человека.

## Границы первой версии

- Solo работает без collaboration server; облачной модели нужен доступ к её провайдеру.
- Управляемая версия DSH и Runlark profile поставляются как один продукт, сначала DSH Web.
- DSH владеет разговором и agent loop; Rust владеет задачей, выполнением и восстановлением.
- Завершение — проверенное локальное изменение или PR, с человеческой приёмкой.
- Автоматический merge, marketplace, произвольное распределённое выполнение и автоматическая
  передача активного run другой машине отложены.
- Sych остаётся обязательным review gate разработки Runlark. В продукте Sych — подключаемый
  reviewer; это разные политики.

## Сохранённые инварианты

Устойчивые ID и неизменяемые тела команд; persist-before-send; версии входов и пакетов в run;
решения, привязанные к конкретному результату; явный unknown до reconciliation; один владелец
активного run; отдельный worktree для каждого параллельно пишущего запуска; лимиты попыток,
времени и расхода. Оценённая, фактическая и неизвестная стоимость различаются.

## Дизайн

Интерфейс доски, экрана задачи и командной работы в `web/` и `@runlark/dsh-plugin` реализует
[визуальный контракт](web/DESIGN.md): тёмная навигация, светлая рабочая область, белые карточки,
золотой акцент `#EDB830`, Manrope и Roboto Mono, desktop/mobile адаптацию, keyboard accessibility
и RU/EN локализацию.
